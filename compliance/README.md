# Mhike School – Compliance Documentation

This directory contains all policies, procedures, and records required for:
- GDPR compliance
- Platform security
- Audit readiness

## Sections

- **gdpr/** → Data protection policies & workflows
- **policies/** → Public-facing policies
- **security/** → Technical safeguards
- **audit/** → Logging and traceability
- **operations/** → Reliability & recovery
- **records/** → Legal records (Article 30 etc.)
- **templates/** → Standard request formats
- **training/** → Internal guidance

## Key Principles

- Least privilege access (RBAC enforced)
- School-level data isolation (multi-tenant)
- Full audit logging for sensitive actions
- Secure authentication (JWT + hashed passwords)
